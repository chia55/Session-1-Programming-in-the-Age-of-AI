# Guide 05 · Where Python is used today

Python is consistently ranked among the most-used programming languages in the world. It's popular because it's **easy to read**, **free**, and has an enormous collection of ready-made **libraries** (packages of code other people wrote that you can reuse).

## 1. Data analysis and statistics 📊

**What:** cleaning, summarising and visualising data to answer questions.

**Libraries:** pandas, Polars, NumPy, DuckDB, seaborn, Plotly, SciPy *(you'll use all of these in Sessions 5–8).*

**Examples:**
- A county health office tracking clinic visits and vaccination rates.
- A retailer finding which products sell best in which branch.
- University students analysing survey data for a research project or thesis.
- Banks and SACCOs looking at loan repayment patterns.

## 2. Artificial intelligence and machine learning 🤖

**What:** building systems that learn patterns from data and make predictions. Many of today's AI tools are built and trained using Python.

**Libraries:** scikit-learn, PyTorch, TensorFlow, Hugging Face Transformers, and SDKs for calling AI models such as Anthropic's `anthropic` or Google's `google-genai`.

**Examples:**
- Credit scoring for mobile loans.
- Crop disease detection from photos of leaves.
- Translating or summarising text in English and Kiswahili.
- Calling an AI model from Python to categorise thousands of survey comments *(Session 8)*.

## 3. Automation and scripting ⚙️

**What:** letting the computer do boring, repetitive work.

**Examples:**
- Renaming 500 photos in one go.
- Combining 47 county Excel files into one report every Monday.
- Sending reminder SMS or emails automatically.
- Downloading data from a website every morning.

> If you do the same task on a computer more than three times, it might be worth automating.

## 4. Web development and APIs 🌐

**What:** the "back end" that powers websites and apps: logins, databases, payments.

**Libraries/frameworks:** Django, Flask, FastAPI.

**Examples:**
- Instagram's back end has famously been built with Django.
- A school portal where students check their results.
- An API that receives M-Pesa payment confirmations *(Session 4 introduces JSON, the format these APIs use)*.

## 5. And much more

Scientific research, finance, cybersecurity, game prototyping, teaching, IoT devices (Raspberry Pi), geography and mapping (GeoPandas)…

## Python in Kenya

Python skills are in demand at banks, telecoms, fintechs, research institutions, NGOs, government agencies and data-focused start-ups. Kenya also has a strong developer community, with meet-ups and events such as **PyCon Kenya** and groups like **Python Nairobi** and **PyLadies**. Find one near you; communities are the fastest way to grow.
